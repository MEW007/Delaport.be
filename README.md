# delaport.be

Website van de Delaport group: **Delaport Irrigation** (automatische tuinberegening) en **Delaport Infrastructure** (scope governance voor grote infrastructuurprojecten).

Gebouwd met [Astro](https://astro.build), gehost op Cloudflare Pages.

```bash
npm install
npm run dev      # lokaal op http://localhost:4321
npm run build    # productiebuild in dist/
```

Instellingen (contact, analytics, formulier, zichtbaarheid van Infrastructure) staan in `src/config.ts`.
Stappenplan en openstaande taken staan in [`ROADMAP.md`](ROADMAP.md).
